## Agent skills

### Issue tracker

Issues and specs live as local markdown under `.scratch/<feature-slug>/` — **not** in GitHub Issues, despite the GitHub remote. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles, each string equal to its name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and one `docs/adr/` at the repo root. See `docs/agents/domain.md`.
